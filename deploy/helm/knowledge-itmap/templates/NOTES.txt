1. Install Knowledge Core (`kc`) in namespace `knowledge-core` first.
2. Add Pocket ID redirect URI: `https://<host>/callback` (same OIDC client as KC).
3. Install (image tags default to Chart.appVersion):

  helm upgrade --install itmap oci://ghcr.io/l-ra/charts/knowledge-itmap \
    --namespace knowledge-core \
    --set knowledgeCore.url=http://kc-knowledge-core:8080

4. UI: http://{{ include "knowledge-itmap.fullname" . }}:{{ .Values.service.port }}
5. MCP (via UI nginx): /mcp — OAuth PRM at /.well-known/oauth-protected-resource/mcp
